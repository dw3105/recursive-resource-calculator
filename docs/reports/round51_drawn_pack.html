Engine facts learned

Flip rule

Mirror x in machine frame, then turn. Box keeps index. Same on 2.0.77 and 2.1.20. am2/am3 Flip changes nothing. Fixture flip_fluidboxes_*.txt.

Fluid box binding

Recipe filling every box of a type: fluid k → box k, Flip swaps sides. Fewer fluids: foundry and chemical plant merge spare connection into used box; refinery keeps fixed box. Fixture flip_filters_*.txt.

Recipe before direction

Crafting machine created without recipe ignores direction. Headless Lab.build built every turned fluid machine facing north; now passes recipe at create.

Main already over 16 ms

Magenta flag-off worst tick 454.5 ms (Groups.step), Pack.step 160 ms, Power.step 157 ms. Drawn now 561.7 ms, same stage.
